# Security

## Reporting a vulnerability

Please do not open a public issue. Use [Report a vulnerability](https://github.com/Thrashy190/Rivo/security/advisories/new), which only the maintainer can see. Say what an attacker could do and how to reproduce it.

Rivo manages access to AWS accounts, so please report anything that could let one workspace reach another workspace's data or accounts.

This is a project maintained in spare time, so an answer can take some days. There is no bug bounty.

## Supported versions

Only the [latest release](https://github.com/Thrashy190/Rivo/releases/latest) gets fixes.
